## How to Contribute Feedback or Report Issues

We appreciate your help in making SCADMan better! Before creating a new issue, please follow these steps:

### 1. Search Existing Issues
Check the **[Issues](../../issues)** tab to see if your bug or feature request has already been reported. If it has, feel free to add a `+1` reaction or comment on that existing issue.

### 2. Submitting a Bug Report
If you found a bug, please [open a new issue](../../issues/new) and provide as much detail as possible:
* **Environment:** Browser version, OS, or device used.
* **Steps to Reproduce:** Clear, step-by-step instructions on how to trigger the bug.
* **Expected vs. Actual Result:** What should have happened versus what actually happened.
* **Media:** Screenshots, video recordings, or browser console error logs (if applicable).

### 3. Requesting a Feature
Have an idea to improve Scadman? We'd love to hear it! [Submit a feature request](../../issues/new) explaining what you'd like to see and why it would be beneficial.
